# 🏦 Banking System - Java

A simple **Banking System desktop application** developed using **Java Swing**. The project provides a graphical user interface (GUI) for performing basic banking operations such as account creation, login, deposits, withdrawals, balance checking, and money transfers.

## 📌 Features

* 🔐 Secure account login using account number and PIN
* 👤 Create a new bank account
* 💰 Deposit money
* 💸 Withdraw money
* 💳 Check account balance
* 👤 View account details
* 🔄 Transfer money between accounts
* 🚪 Logout and exit options
* 🖥️ User-friendly graphical interface
* ⚠️ Input validation and error messages

## 🛠️ Technologies Used

* **Java**
* **Java Swing**
* **AWT**
* **HashMap**
* **Object-Oriented Programming (OOP)**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Muskanshaik-13/Banking-System-Java.git
```

### 2. Open the project folder

```bash
cd Banking-System-Java
```

### 3. Compile the Java program

```bash
javac BankingSystem.java
```

### 4. Run the application

```bash
java BankingSystem
```

## 💻 Banking Operations

After logging in, the dashboard provides the following options:

| Option             | Description                       |
| ------------------ | --------------------------------- |
| 💰 Deposit         | Add money to the account          |
| 💸 Withdraw        | Withdraw money from the account   |
| 💳 Balance         | Display the current balance       |
| 👤 Account Details | Display account information       |
| 🔄 Transfer        | Transfer money to another account |
| 🚪 Logout          | Return to the login screen        |
| ❌ Exit             | Close the application             |

## 🎯 Project Objective

The main objective of this project is to demonstrate the use of **Java programming, object-oriented concepts, GUI development, event handling, collections, and basic banking operations** in a single desktop application.

## 📚 Concepts Demonstrated

* Classes and Objects
* Constructors
* Encapsulation
* Collections using `HashMap`
* Event Handling
* Java Swing GUI
* Exception Handling
* Conditional Statements
* Methods
* User Input Validation
